## Project Overview

Bikelencia is an iOS app that shows bike parking locations in Valencia, Spain. This is a monorepo with four workspaces:

- **app/** — iOS app (SwiftUI, managed by Tuist)
- **web/** — Marketing site (Next.js 16)
- **api/** — Static JSON API (pre-built data files served via Vercel)
- **resources/** — Shared assets (app icon source files)

## Tool Versions

Managed via `mise.toml`: Node LTS, Tuist latest, Deno latest, Corepack latest.

Package manager: **Yarn 4.12.0** (via Corepack). Do not use npm.

## Commands

### Monorepo (root)

```bash
yarn install          # Install all JS dependencies
yarn prettier --check .  # Check formatting
yarn prettier --write .  # Fix formatting
```

### API (`api/`)

```bash
yarn workspace @bikelencia/api build   # Regenerate static JSON into api/public/
# or: cd api && node ./src/build.ts ./public
```

The build fetches GeoJSON from Valencia's OpenDataSoft API and outputs `bike-parkings.json` and `manifest.json`. A GitHub Actions cron job triggers a Vercel redeploy daily at midnight UTC to refresh the data.

### Web (`web/`)

```bash
cd web
yarn dev       # Dev server (Next.js with webpack)
yarn build     # Production build
yarn start     # Serve production build
```

ESLint config is at `web/eslint.config.js` (flat config format). No explicit lint script — run `npx eslint .` from `web/`.

### iOS App (`app/`)

```bash
cd app
tuist generate   # Generate Xcode project from Project.swift
# Then build/run from Xcode
```

No test targets exist. The Xcode project and workspace files are gitignored and regenerated by Tuist.

## Architecture

### iOS App

The Xcode project is generated by Tuist from `app/Project.swift`. The `Bikelencia.xcodeproj` and `Bikelencia.xcworkspace` files are ignored and should not be modified directly, but regnerated via `tuist generate` after any changes to `Project.swift`.

- **Bikelencia** (app target) — SwiftUI app with MapKit and ClusterMap for annotation clustering
- **BikelenciaCore** (framework target) — `SpotsController` (data fetch/cache with 30-day TTL), `StoredJSON` (actor-based file persistence)
- **ValenciaKit** (local Swift package) — API client that fetches from `https://api.bikelencia.precioso.design/api/bike-parkings`

State management: `@Observable` objects passed via SwiftUI `@Environment`. No third-party state management.

Localized in English, Spanish, and Catalan via `.xcstrings` string catalogs.

Code style: 2-space indentation (configured in Project.swift).

### API Server

Not a running server — just static JSON files in `api/public/`. The Vercel config (`api/vercel.json`) rewrites `/api/bike-parkings` to `/bike-parkings.json`. The build script (`api/src/build.ts`) runs as a plain Node.js TypeScript file (no compilation step needed).

### Marketing Site

Next.js App Router with locale-based routing (`[locale]` dynamic segment for en/es/ca). Uses Vanilla Extract (`*.css.ts` files) for styling. Language detection via `Accept-Language` header negotiation in `src/proxy.ts`. All pages are statically generated.

Path alias: `@/*` maps to `web/src/*`.

## Formatting

Prettier is configured at the repo root with plugins for import sorting (`prettier-plugin-organize-imports`), `package.json` formatting (`prettier-plugin-pkg`), and shell scripts (`prettier-plugin-sh`).
